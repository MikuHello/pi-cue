# pi-cue project guidance

This file adds repository conventions. Keep all applicable user and parent instructions, including existing communication style and work ownership.

- Preview README changes at desktop and mobile widths. Keep image paths relative and commands copyable. Locally installed authoring skills are optional tools and are not distributed with this repository.
- Follow [CONTRIBUTING.md](CONTRIBUTING.md) for Conventional Commits structure and Gitmoji semantics. The optional local checker is `node scripts/check-commit-message.ts <message-file>`; no Git hook is installed automatically.
- Keep local configuration, credentials, sessions, authoring skills and preview artifacts out of commits. The entire `.codex` and `.agents` directories stay local.
- During the current publication preparation, show the updated README for approval before rewriting remote history or pushing the replacement initial commit. Package publication and release automation require their own explicit authorization.
