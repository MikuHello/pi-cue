# README visual sources

- `hero.svg` is a static, project-specific SVG. It uses system fonts, literal `/cue` commands and no remote resources, scripts or animation.
- `sound-settings.png` is a fresh render of the production `CuePanel` at 40 columns, using the Pi 1.4.0 dark theme and an isolated Simplified Chinese configuration. Text and colors come from the actual component’s ANSI output; the PNG was rendered at double density for readability. It contains no personal terminal background, session data or operating-system notification.

The interface image illustrates settings, not proof of native notification delivery. No notification or sound was triggered to produce it. These original documentation assets are covered by the project’s MIT license.
